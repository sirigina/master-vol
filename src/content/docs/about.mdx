## Lesson structure

Each lesson has an ID (module letter + number), a list of lessons it builds on, two explanation layers, interactive figures, key takeaways, and a short self-check. Use **Explain it: Both / Plain English / Pro** at the top of any lesson; your choice is remembered on this device.

## The analogy set

To keep the plain-English layer consistent, the same analogies are used everywhere:

| Concept | Analogy |
| --- | --- |
| An option | A deposit that holds a price for you; for puts, an insurance policy |
| Premium | The deposit or insurance payment |
| Volatility | A weather forecast for price swings: how big, not which direction |
| Implied vs realized volatility | The forecast vs the weather that actually happened |
| Delta | A speedometer: how fast the option moves relative to the stock |
| Gamma | The accelerator: how fast delta itself changes |
| Theta | Melting ice: value that drains away each day |

## About the market data

Examples use a single **static snapshot**: SPY and its options at the close on October 27, 2026, pulled at the time the site was built. Every example that uses market data says so. Prices have moved since; the concepts don't depend on them. Where a calculation needs an interest rate, we use the rate implied by the option prices themselves (put-call parity), about 4.6% at the snapshot.
