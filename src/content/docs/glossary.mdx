---
title: Glossary
description: Short definitions of the terms used across the course, with the lesson where each is taught.
---

Terms are grouped alphabetically. The lesson column links to where the idea is taught in depth.

| Term | Meaning | Lesson |
| --- | --- | --- |
| American option | Can be exercised any time before expiration | [A1](/vol/a1/) |
| Assignment | Being required to fulfil an option you sold, because the holder exercised | [A2](/vol/a2/) |
| At the money (ATM) | Strike at or near the current price | [A3](/vol/a3/) |
| Backspread | Buying more options than you sell, usually net long volatility | [G5](/vol/g5/) |
| Basis | The difference between a futures price and the underlying index | [J2](/vol/j2/) |
| Bid / ask | The best prices to sell to / buy from the market | [A4](/vol/a4/) |
| Binomial model | Prices an option on a tree of up and down moves | [B5](/vol/b5/) |
| Black-Scholes | The standard model for European option prices | [B4](/vol/b4/) |
| Box spread | Bull call spread plus bear put spread; a fixed payoff that implies a rate | [F4](/vol/f4/) |
| Breakeven | Underlying price at expiration where a position neither makes nor loses money | [A5](/vol/a5/) |
| Butterfly | Long one strike, short two of the middle strike, long one higher strike | [G4](/vol/g4/) |
| Calendar spread | Same strike, different expirations: sell near, buy far | [G6](/vol/g6/) |
| Call | Right to buy the underlying at the strike | [A1](/vol/a1/) |
| Cash settlement | Expiration paid in cash rather than delivering shares (e.g. SPX) | [A2](/vol/a2/) |
| Collar | Long stock, long put, short call; protection paid for by giving up upside | [I1](/vol/i1/) |
| Condor | A butterfly with the middle strikes split apart | [G4](/vol/g4/) |
| Conversion / reversal | Stock plus synthetic opposite position; locks in a financing spread | [F3](/vol/f3/) |
| Cost of carry | Interest minus dividends from holding the underlying | [B3](/vol/b3/) |
| Covered call | Long stock plus a short call | [A6](/vol/a6/) |
| Delta | Change in option value per $1 change in the underlying; also hedge ratio and share equivalent | [D1](/vol/d1/) |
| Delta-neutral | A position whose total delta is zero | [E2](/vol/e2/) |
| Dispersion | Index volatility vs the volatility of its members; driven by correlation | [J3](/vol/j3/) |
| Early exercise | Exercising an American option before expiration | [F6](/vol/f6/) |
| Edge | Theoretical value minus market price, in dollars or volatility points | [E1](/vol/e1/) |
| Elasticity (lambda) | Percent change in option value per 1% change in the underlying | [D7](/vol/d7/) |
| European option | Can be exercised only at expiration | [A1](/vol/a1/) |
| Expected move | Price range implied by volatility over a horizon, usually ±1 standard deviation | [C2](/vol/c2/) |
| Expected value | Probability-weighted average payoff | [B1](/vol/b1/) |
| Extrinsic (time) value | Option price minus intrinsic value | [A3](/vol/a3/) |
| Fat tails | More extreme moves than a normal distribution predicts | [C2](/vol/c2/) |
| Forward price | The fair price today for delivery later: S·e^((r−q)T) | [B3](/vol/b3/) |
| Forward volatility | Volatility implied between two future dates | [C7](/vol/c7/) |
| Gamma | Change in delta per $1 change in the underlying | [D2](/vol/d2/) |
| Historical volatility | Annualized standard deviation of past returns | [C4](/vol/c4/) |
| Implied volatility | The volatility that makes a pricing model match an option's market price | [B6](/vol/b6/) |
| In the money (ITM) | Has intrinsic value: call strike below price, put strike above | [A3](/vol/a3/) |
| Intrinsic value | What an option would be worth if exercised now | [A3](/vol/a3/) |
| Iron condor | Short put spread plus short call spread | [G4](/vol/g4/) |
| IV crush | The drop in implied volatility after an expected event like earnings | [C7](/vol/c7/) |
| Jelly roll | Long a synthetic in one expiry, short in another | [F4](/vol/f4/) |
| Lognormal | Distribution where log returns are normal; prices can't go negative | [C3](/vol/c3/) |
| Mean reversion | Volatility's tendency to drift back toward its long-run average | [C6](/vol/c6/) |
| Moneyness | Where the strike sits relative to the underlying price | [A3](/vol/a3/) |
| Normal distribution | The bell curve; ±1 SD covers about 68% of outcomes | [C1](/vol/c1/) |
| Out of the money (OTM) | No intrinsic value | [A3](/vol/a3/) |
| Payoff diagram | Profit or loss at expiration plotted against the underlying price | [A5](/vol/a5/) |
| Pin risk | Uncertainty about assignment when the price finishes at a strike | [F5](/vol/f5/) |
| Position Greeks | Greeks summed across all legs of a position | [H2](/vol/h2/) |
| Protective put | Long stock plus a long put | [I1](/vol/i1/) |
| Put | Right to sell the underlying at the strike | [A1](/vol/a1/) |
| Put-call parity | C − P = S − PV(K) (− PV of dividends) | [F2](/vol/f2/) |
| Ratio spread | Selling more options than you buy, usually net short volatility | [G5](/vol/g5/) |
| Realized volatility | Annualized standard deviation of actual returns | [C2](/vol/c2/) |
| Rho | Change in option value per 1-point change in interest rates | [D5](/vol/d5/) |
| Risk reversal | Difference between OTM put and OTM call implied vols; a skew measure | [C8](/vol/c8/) |
| Rule of 16 | Annual volatility ÷ 16 ≈ typical daily move | [C2](/vol/c2/) |
| Scenario analysis | Full revaluation of a position across price, volatility and time | [H3](/vol/h3/) |
| Skew / smile | Implied volatility varying by strike | [C8](/vol/c8/) |
| Straddle | A call and a put at the same strike and expiry | [G3](/vol/g3/) |
| Strangle | An OTM call and an OTM put, same expiry | [G3](/vol/g3/) |
| Strike | The price at which an option lets you buy or sell | [A1](/vol/a1/) |
| Synthetic | A combination that replicates another instrument's payoff | [F1](/vol/f1/) |
| Term structure | Implied volatility across expirations | [C7](/vol/c7/) |
| Theoretical value | A model's fair price given your inputs | [B1](/vol/b1/) |
| Theta | Change in option value per day of passing time | [D3](/vol/d3/) |
| Vega | Change in option value per 1-point change in volatility | [D4](/vol/d4/) |
| Vertical spread | Long and short options at different strikes, same expiry | [G8](/vol/g8/) |
| VIX | 30-day implied volatility of the S&P 500, from SPX options | [C5](/vol/c5/) |
| Volatility | Annualized standard deviation of returns | [C2](/vol/c2/) |
| Volatility cone | Range of realized volatility by look-back window | [C6](/vol/c6/) |
| Volatility risk premium | The tendency of implied volatility to exceed subsequent realized volatility | [C2](/vol/c2/) |
